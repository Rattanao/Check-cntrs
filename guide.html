Check CNTRS

ตรวจเทียบ MANIFEST ของสายเรือกับ CNTRS (Container List for Feeder) ให้ครบทุกตู้ แล้วออกรายงาน CNTRS_EDI.xlsx แบบใส่สี จุดไหนไม่ตรงเห็นได้ทันทีก่อนยื่นใบขน

MANIFEST.xls+ CNTRS.xls / .pdf→ CNTRS_EDI.xlsx
ตรวจออนไลน์ (ไม่ต้องติดตั้ง) ดาวน์โหลดโปรแกรม (ZIP) เปิดหน้า GitHub

ติดตั้งครั้งแรก

ทำครั้งเดียวต่อเครื่อง ใช้ Windows (หรือจะใช้ "ตรวจออนไลน์" ด้านบนแทนก็ไม่ต้องติดตั้งอะไรเลย)

  1. ติดตั้ง Python 3 จาก python.org/downloads

    หน้าแรกของตัวติดตั้ง ติ๊ก ☑ Add python.exe to PATH ก่อนกด Install Now

  2. ดาวน์โหลดโปรแกรม กดปุ่ม "ดาวน์โหลดโปรแกรม (ZIP)" ด้านบน

    คลิกขวาที่ไฟล์ ZIP → Extract All แล้วเก็บโฟลเดอร์ไว้ที่ไหนก็ได้ เช่น Documents

  3. รันครั้งแรกต้องต่ออินเทอร์เน็ต

    โปรแกรมจะติดตั้งไลบรารีที่ต้องใช้ (pandas, openpyxl, xlrd, pdfplumber) ให้เองอัตโนมัติ

ใช้งานทุกครั้ง

  1. วางไฟล์ในโฟลเดอร์ input

    วางไฟล์ MANIFEST (.xls/.xlsx) 1 ไฟล์ และ CNTRS (.xls/.xlsx หรือ .pdf) อย่างน้อย 1 ไฟล์ — ตั้งชื่อไฟล์อะไรก็ได้ โปรแกรมแยกประเภทจากเนื้อหาในไฟล์ให้เอง ไม่ต้องขึ้นต้นด้วยชื่อเฉพาะ และวาง CNTRS ได้หลายไฟล์พร้อมกัน (เช่น แยกตามปลายทาง BMT/LCH/LKR) โปรแกรมจะรวมให้เป็นชุดเดียว

  2. ดับเบิลคลิก run-check-cntrs.bat

  3. เปิดผลที่ output\CNTRS_EDI.xlsx

    หน้าจอดำจะสรุปจำนวนตู้ที่ตรวจพบและไม่ตรงกันให้ด้วย ถ้าเปิด CNTRS_EDI.xlsx ค้างไว้ใน Excel โปรแกรมจะบันทึกเป็นชื่อใหม่ (เช่น CNTRS_EDI_2.xlsx) ให้เองโดยไม่ทับไฟล์เดิม

อ่านรายงาน CNTRS_EDI.xlsx

หนึ่งแถวต่อหนึ่งตู้คอนเทนเนอร์ คอลัมน์ของ MANIFEST กับ CNTRS วางคู่กันทุกหัวข้อ ช่องที่ตรงกันแสดง "-" เฉยๆ ช่องที่ไม่ตรงจะโชว์ค่าจริงทั้งสองฝั่งพร้อมพื้นแดงให้เห็นทันที

หัวข้อที่เทียบทุกตู้

  • SHED NUMBER (เทียบตรงตามที่เห็น + กฎล็อก DG=2826 เฉพาะปลายทาง THLCH, BMT=0110, ลาดกระบัง=0332)
  • STATUS (FCL / LCL)
  • TEMP ของตู้เย็น (REEFER)
  • VENT — ตู้เย็นต้องมีระบุใน MANIFEST เสมอ
  • DG CLASS / UN (เทียบเลข UN เป็นหลัก)
  • REMARK ตามปลายทาง: BMT=BY BARGE, SCT=BY TRUCK, LKR=BY TRUCK (ตู้เย็น/DG) นอกนั้น BY TRAIN

ขึ้นแดง/เหลืองทันทีเมื่อเจอ

  • ตู้ที่มีใน CNTRS แต่หายจาก MANIFEST หรือกลับกัน (แถววิกฤต)
  • SHED ผิดกฎที่ล็อกไว้ตามปลายทาง
  • REMARK ของ TRANSIT ไม่ครบ ต้องมีทั้งคำว่า TRANSIT และ "TO <ประเทศ>"
  • TEMP ไม่ตรงกัน หรือตู้เย็นไม่มี VENT
  • DG CLASS/UN ไม่ตรงกัน
